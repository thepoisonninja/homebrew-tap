# thepoisonninja/tap

Homebrew casks for [Converterator](https://github.com/thepoisonninja/Converterator), a macOS app that converts
disc images to CHD (or PBP for a PSP / PS Vita), with Redump checks and translation patches.

```bash
brew install --cask thepoisonninja/tap/converterator
```

Converterator updates itself (Check for Updates → Install and Relaunch), so `brew upgrade` leaves it alone
unless you use `--greedy`. The cask is updated automatically with each release.
